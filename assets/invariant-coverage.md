## What this is

Every invariant openEHR RM 1.1.0 declares, against whether the `openehr`
crate's source **names** it.

**Naming is not enforcing.** This is a grep. A name present means the
rule was written down beside code; a name absent means only that this
crude test did not find it. It MUST NOT be promoted to a conformance
claim (`db:C0.20`) — the [conformance matrix](../spec/databases/conformance-matrix.md)
is where verified status lives.

It is still worth having: before it existed, the question had no answer,
and the two invariants that turned out to be neither enforced nor
declared were invisible (`lib:A-19`).

Source: the openEHR BMM, which carries invariant **expressions** and not
merely names — see `rm-1.1.0-invariants.json`.
